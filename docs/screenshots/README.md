## Tips

- Capture at **1920×1080** or wider so text stays legible on GitHub.
- Prefer **`.webp`** or optimised `.png`. Some browser captures are 1–3 MB each;
  converting to WebP usually cuts that by 70–90 %. Keep each file under ~500 KB.
- Crop out the browser chrome and the address bar unless you want to show the URL.
- Use a dark background for dark-mode screens so the edges blend into the README.
